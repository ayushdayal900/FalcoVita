# FalcoVita Frontend Setup

## Prerequisites

- Node.js 20.19.0+ or 22.12.0+ (as per `package.json`)
- npm (Node Package Manager)

## 1. Install Dependencies

Run the following command from the root `FalcoVita` directory:

```powershell
cd frontend
npm install
```

## 2. Run the Application

### Start the Development Server
In your Terminal (Bash or PowerShell):

```bash
# Make sure you are in the FalcoVita/frontend directory
npm run dev
```

The application will typically start at `http://localhost:5173`.

## 3. Build for Production

To build the application for production:

```powershell
npm run build
```

To preview the production build:

```powershell
npm run preview
```
