FalcoVita - It is the Hospital Management System (HMS) V2 is a web application that streamlines hospital operations by managing patients, doctors, appointments, and treatments. It provides role-based access for Admins, Doctors, and Patients, allowing efficient scheduling, record-keeping, and treatment tracking. Built with Flask, VueJS, Bootstrap, SQLite, and Redis, the system improves hospital efficiency, reduces conflicts, and enhances patient care.
